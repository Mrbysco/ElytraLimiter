# Elytra Limiter #

## About ##
Elytra Limiter allows configuring certain dimensions to have elytra flight restricted.

The mod comes with the following config options:
- **restrictedDimensions** - A list of dimension identifiers in which elytra flight is restricted (For example `["minecraft:overworld"]`)
- **showMessage** - Whether to show a message when elytra flight is restricted
